`local_up1_metadata`

Installe les métadonnées de cours spécifiques UP1.

Depuis Moodle 3.9 (2020), utilise les métadonnées standard de Moodle (`customfield_*`).

Code réécrit pour Moodle 4.5+ (2026) et les champs syllabus (`syl_`) :
`classes/customfields.php` et `cli/install-customfields.php`.
